Operator access to this server: the accounts it holds, the data they stored, and the device tokens that reach it.

Set TABVERSED_ADMIN_TOKEN on the server to enable this. It is stored in this browser's localStorage only.

    Pairing codes

    A code adds a device to this account. It works once and expires; the device exchanges it for its own token.

    Device tokens

    Every device holds a token. The server only stores its hash, so a token cannot be shown again - revoking one is final, and the device has to pair again.
