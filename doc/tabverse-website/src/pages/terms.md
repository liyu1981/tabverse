  address you control, and you are responsible for keeping access to that

- Do not create an account for somebody else, and do not register an address
  that is not yours.
- The server operator may disable or delete an account. Deleting an account
  removes the data that account stored on the server.

**Your content**

- What you sync is yours. The server stores it so your devices can stay in

- An operator of the server can see the data stored on their own machine; that
  is what the operator's console is for. The server operator is responsible for
  saying so in their own privacy notice.
- Do not use the server to store or share content you have no right to.
