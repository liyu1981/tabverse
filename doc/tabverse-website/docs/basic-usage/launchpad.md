# Launchpad

The Launchpad is a page of tiles for the web tools you open all day. It is
**account level**: a shortcut is saved once and is available from every
tabverse in every window, unlike a bookmark, which belongs to one tabverse.

Open it from **Launchpad** in the manager sidebar, below Search. It looks like
a home screen: a large icon and a name for each page, and clicking one opens it
in a new tab.

## Add a shortcut

There is no "add" form; a page becomes a shortcut from where you already are:

- **From a tab** - the tile button on a tab row ("Add this tab to Launchpad").
- **From a bookmark** - the tile button on the bookmark's row.
- **From the history** - the tile button on a closed tab. Unlike "save as
  bookmark", this does **not** remove the page from the history.
- **From the toolbar popup** - the tile button in the popup's header adds the
  tab you opened the popup on.

The page's title and its icon are captured at that moment. The icon is the
site's own large icon (the one it ships for a phone's home screen), fetched
once and stored with the shortcut, so a tile still has its picture on another
device, offline, or after the site changes its favicon. A site with no usable
icon shows a monogram instead.

Adding the same page twice keeps the first shortcut and says "Already in
Launchpad".

## Use the page

- **Open** - click a tile (or middle-click / Ctrl-click) to open the page in a
  new tab.
- **Filter** - the box narrows the grid by name and url.
- **Order** - the two buttons sort by name (the default) or by newest first.
  The choice is remembered in this browser.
- **Delete** - the bin button on a tile, shown when the pointer is over it.

Shortcuts are synced with the rest of your account when you pair a server, so
the Launchpad follows you to your other browsers. No account is needed: without
one, the page is local to this browser, like everything else.
